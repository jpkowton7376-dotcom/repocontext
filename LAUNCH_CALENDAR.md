# RepoContext — Product Hunt Launch Calendar

A day-by-day execution calendar. Primary launch is Product Hunt (EN); the es/ja
localized pushes go out a few hours later (see `PRODUCT_HUNT_LAUNCH.md` §7).

## T-7 (one week before)
- [ ] Finalize the PH listing draft (tagline ≤60 chars, topics, 3–5 gallery images) in `PRODUCT_HUNT_LAUNCH.md`.
- [ ] Capture 3–4 **real** product screenshots: homepage input, result page, multi-format output, quality score.
- [ ] Confirm the 6 blog posts are live AND submitted to GSC/Bing so they can rank during launch week.
- [ ] Line up 3–5 friends / early users to comment in the first hour (organic only — never pay).
- [ ] Pre-write X / Reddit / es / ja snippets (ready to paste).
- [ ] Make sure an email/waitlist capture exists on the site.

## T-3
- [ ] Lock the launch for **Tue–Thu, 12:01 AM PT** (best traffic).
- [ ] Pre-write the PH draft in the console (do NOT publish yet).
- [ ] Prepare the "Featured on Product Hunt" footer badge (hidden until live).
- [ ] Warm up the X account with a few normal tweets so the launch tweet isn't the first in months.

## T-1
- [ ] Upload gallery images (image #1 = hero, must read well on its own at 1270×760).
- [ ] Final proofread of the maker comment.
- [ ] Tell your email list / existing users: "We launch on PH tomorrow."
- [ ] Set a 12:01 AM PT alarm.

## T-0 (launch day)
- [ ] **12:01 AM PT** — publish the PH listing.
- [ ] Within **5 min** — post the maker comment.
- [ ] Within **1 hr** — post X launch tweet + 2 Reddit threads (r/cursor, r/ClaudeAI).
- [ ] First **2–3 hrs** — reply to **every** comment. Engagement drives rank.
- [ ] A few hrs later — post **es + ja** localized snippets (NOT the same minute as EN).
- [ ] Mid-day — check rank, publicly thank early commenters.
- [ ] End of day — screenshot the final rank for the badge.

## T+1
- [ ] Thank the top commenters.
- [ ] Add the "Featured on Product Hunt" badge to the footer.
- [ ] Repurpose the maker comment into a **Show HN** post (Hacker News).
- [ ] Post a short launch recap / lessons on X.

## T+3
- [ ] Re-submit / refresh the sitemap (new backlinks may have appeared).
- [ ] Outreach to **Cursor Directory / ClawHub / awesome-claude-agents**.
- [ ] Reply to any late PH comments.

## T+7
- [ ] Review Search Console **Performance** for new queries.
- [ ] Write a follow-up blog post ("How we launched RepoContext on Product Hunt").
- [ ] Pick the next growth loop (guest posts, newsletters, dev communities).

## Pre-flight checklist (run at T-1)
- [ ] PH account aged & with some history (new accounts get flagged).
- [ ] Gallery image #1 is the generated hero or a real screenshot.
- [ ] Maker comment copied to clipboard.
- [ ] X / Reddit / es / ja snippets copied to clipboard.
- [ ] "Featured on Product Hunt" badge ready to toggle on.
- [ ] Analytics / Search Console open in a tab to watch live.
