RepoContext — 自定义域名 + Cloudflare 配置步骤

给站长 列粤湘 / jpkowton — 配合 Creem 账户审核与品牌邮箱需求
最后更新：2026-09-11

背景：Creem 审核要求网站部署在自定义域名（不能用 repocontext.vercel.app）， 且支持邮箱必须是品牌邮箱（@repocontext.com）。 本文档分 7 步搞定域名 + 邮箱转发 + Vercel 接入 + Resend 验证 + Creem 改邮箱。

1注册 Cloudflare 账号

2 分钟你做

  1. 打开 https://dash.cloudflare.com/sign-up
  2. 用 163 邮箱或 QQ 邮箱注册（暂不要用 Gmail，刚改的 repocontext.com 还没生效）
  3. 收验证邮件 → 点链接激活
  4. 登录后会自动跳到 "Add your first site" 页面

2购买 repocontext.com 域名

5 分钟你做

  1. Cloudflare Dashboard 顶部 → Domain Registration → Register Domains
  2. 搜索框输入 repocontext.com
  3. 如果显示 $9.15/year 旁边有 Purchase 按钮 → 可买
如果显示 "Already registered"：立即告诉我，我们改用：
  • repocontext.app（$11/年）
  • repocontext.dev（$12/年）
  • repocontext.io（$30/年）
  1. 加购物车 → Continue → 选 1 year
  2. 填 Contact Information（Cloudflare 不严，简化即可）：
    字段填什么
    First nameYuexiang 或 Kowton
    Last nameLie
    Organization留空
    Address 1Longgang District, Shenzhen
    CityShenzhen
    StateGuangdong

    Phone+86 138 xxxx xxxx
  3. 付款方式选 Credit Card → 输入招行 Visa 卡号（16 位）
  4. 招行 App 弹 3DS 验证 → 点确认
  5. 扣款 $9.15（约 ¥66）
✅ 购买完成。域名所有权立即生效。

3把域名绑到 Vercel

3 分钟你做

  1. 新标签页打开 Vercel：https://vercel.com/dashboard → 选 repocontext-git 项目
  2. Settings → Domains → 输入 repocontext.com → Add
  3. Vercel 可能提示 "Invalid Configuration"，先不管（DNS 还没配）
  4. 回到 Cloudflare → 左侧 DNS → Records → Add record，加 2 条：
    TypeNameTargetProxy
    CNAME@cname.vercel-dns.comDNS only（灰色云朵）⚠️
    CNAMEwwwcname.vercel-dns.comDNS only（灰色云朵）⚠️
⚠️ Proxy 必须关（灰色云朵）！开了橙色 Proxy 会破坏 Vercel 的 SSL 验证，域名永远 Invalid。
  1. 回到 Vercel → 等 1-2 分钟，状态从 "Invalid" 变 "Valid"
✅ Vercel 自动签发 SSL。访问 https://repocontext.com 应能看到你的网站。

4配 Cloudflare Email Routing（品牌邮箱转发）

5 分钟你做

  1. Cloudflare 左侧 → Email → Email Routing → Get started
  2. 同意让 Cloudflare 管理你的 MX 记录（自动加）
  3. Add new rule：
    • Custom address: support
    • Destination: jpkowton@gmail.com
  4. 点 Save
  5. Cloudflare 给 jpkowton@gmail.com 发验证邮件 → 登录 Gmail 找 → 点 Confirm 链接
  6. 回到 Cloudflare 状态变成 "Verified"
✅ 邮箱转发生效。让朋友发邮件到 support@repocontext.com，你的 Gmail 能收到。

回信时显示品牌邮箱（推荐开启）

在 Cloudflare Email Routing 的 Settings 里开启 "Send emails from your custom address"。 这样你在 Gmail 回复时，对方看到的 From 是 support@repocontext.com（不是你个人 Gmail）。

5Resend 验证域名（让通知邮件用品牌 From）

10 分钟你做 — 可选但推荐

不做的后果：RepoContext 给客户发的通知邮件 From 是 onboarding@resend.dev（带 via resend.dev 字样，不专业）。
做了之后：From 是 RepoContext <noreply@repocontext.com>，看起来是你自己发的。

  1. 打开 https://resend.com/domains → Add Domain → 输入 repocontext.com
  2. Resend 给你 DNS 记录，3 条加到 Cloudflare DNS：
    TypeNameValue
    TXT@v=spf1 include:_spf.resend.com ~all
    TXTresend._domainkey（Resend 给的一长串 DKIM）
    TXT_dmarcv=DMARC1; p=none;
  3. 回 Resend → 点 Verify → 等 1-2 分钟通过
  4. 告诉我已验证，我把 RESEND_FROM=RepoContext <noreply@repocontext.com> 加到 Vercel env

6改 Creem 后台邮箱 + 触发复审

3 分钟你做

  1. 登录 https://creem.io → 右上角头像 → Settings → Account / Business
  2. 找 Support email 字段（也可能在 Payout Account 页面）
  3. 改成 support@repocontext.com
  4. 保存
  5. 进入 Payout Account → 找 Request re-review 按钮 → 点击
关于 Gmail vs 品牌邮箱：Creem 偏好品牌邮箱（自定义域名），gmail.com 可能仍被接受。 但用了 repocontext.com 之后，你用真品牌邮箱，Creem 一次性过审没争议。

7告诉我，我做最后一步

5 分钟我做

前 6 步配好后跟我说，我会：

  1. 改 Vercel 环境变量 NEXT_PUBLIC_SITE_URL = https://repocontext.com
